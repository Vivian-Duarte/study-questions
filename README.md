
# Study Questions

Gerador de perguntas de estudo a partir de materiais didáticos
utilizando modelos de linguagem (LLMs).

## Objetivo

Facilitar a criação de perguntas de revisão utilizando
materiais fornecidos pelos estudantes.

## Tecnologias

- Python 3.11+
- Pydantic v2 (planejado)
- Pytest
- Ruff
- mypy
- Gemini API (planejado)
- Streamlit (planejado)

## Estado do projeto

Em desenvolvimento.

## Arquitetura

O projeto utiliza uma estrutura modular com layout src/,
priorizando testes automatizados, tipagem estática
e separação de responsabilidades.
